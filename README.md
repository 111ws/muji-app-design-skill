A portable AI skill that encodes the design principles of MUJI style mobile apps.  
Load this skill into any compatible AI tool to get expert recommendations on minimalist app design.

## What is this?

This repository contains a **skill** — a structured set of instructions and knowledge that can be loaded into AI assistants (like Claude, ChatGPT, or custom agents).  
Once loaded, the AI can:

- Evaluate your app's information architecture against MUJI style principles.
- Suggest navigation structures, content priorities, and launch page strategies.
- Provide actionable design recommendations for minimalist mobile apps.

## How to Use

### For AI Tools

1. Download or clone this repository.
2. Copy the content of [`muji-style-app-design/SKILL.md`](.muji-style-app-design/SKILL.mdd).
3. Paste it into your AI tool as a system prompt or knowledge base.
4. Start asking questions like:
   - "How should I design the navigation for my minimalist shopping app?"
   - "Where should I place discount information?"
   - "What is the best launch page strategy for a high-frequency points feature?"

### For Humans

You can also read the skill file directly as a comprehensive design guide.  
See [`skill/SKILL.md`](./skill/SKILL.md) for the full content.
