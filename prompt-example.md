# AI Design Prompt Example


Create a minimalist mobile application inspired by MUJI.


Requirements:


## Information Architecture

- Use maximum 5 navigation items.
- Prioritize user goals.
- Hide secondary functions.


## UX

Reduce cognitive load.

Avoid feature overload.

Every visible element must have a clear purpose.


## Visual Style

Use:

- calm typography
- generous whitespace
- natural colors
- functional layouts


Avoid:

- excessive cards
- unnecessary animations
- aggressive marketing banners


The final design should feel:

quiet,
human,
timeless,
and intentional.
