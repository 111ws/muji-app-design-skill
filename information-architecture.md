# Information Architecture Reference


## Principle

Structure information according to:

user mental model

not:

company organization structure.


---

# Three Layer Model


## Surface Layer

Immediately visible.

Contains:

high-frequency actions.


## Context Layer

Appears when needed.

Contains:

supporting functions.


## Deep Layer

Hidden.

Contains:

rare functions.


---

# Navigation Decision Framework


Evaluate each feature:

1. How frequently is it used?
2. How important is it?
3. How long does interaction last?
4. Does it require immediate access?


Then decide:

Visible / Contextual / Hidden
