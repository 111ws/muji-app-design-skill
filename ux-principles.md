# UX Principles Reference


## Cognitive Load Reduction

Users have limited attention.

Good interfaces reduce:

- memory requirements
- unnecessary choices
- visual complexity


---

## Hick's Law

More choices increase decision time.

Therefore:

Reduce visible options.


---

## Jakob's Law

Users expect familiar interaction patterns.

Maintain:

- predictable navigation
- consistent behavior


---

## Progressive Disclosure

Show:

what users need now.

Hide:

what users may need later.
