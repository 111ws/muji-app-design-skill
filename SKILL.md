# MUJI Style App Design Skill


## Purpose

Use this skill when designing:

- mobile applications
- SaaS products
- AI interfaces
- accessibility tools
- productivity applications


The goal:

Create interfaces that are:

- simple
- calm
- intentional
- human-centered


---

# Core Principle

Minimalism means removing unnecessary complexity.

It does NOT mean:

- fewer features
- empty screens
- decorative simplicity


The question:

"Does this element help the user's intention?"

If not:

remove it,
hide it,
or simplify it.


---

# Information Architecture


## Navigation

Primary navigation:

Maximum 5 destinations.

Recommended:

3-5 tabs.


Navigation represents:

- repeated user goals
- important states
- frequent actions


Avoid:

- feature-based navigation
- exposing every capability


---

# Feature Hierarchy


## Level 1: Core

Visible immediately.

Examples:

- create
- search
- purchase
- check status


## Level 2: Supporting

Accessible contextually.

Examples:

- filters
- recommendations
- history


## Level 3: Advanced

Hidden.

Examples:

- settings
- account management
- rarely used tools


---

# Launch Experience


The first screen should answer:

"What does the user want now?"


Do not optimize for:

"What does the company want to show?"


---

# Visual System


## Color

Prefer:

- neutral colors
- natural tones
- low saturation


Avoid:

- excessive gradients
- promotional colors


## Typography

Use:

- clear hierarchy
- generous spacing
- readable scale


Avoid:

- dense information
- unnecessary styles


---

# Interaction


Reduce:

- decisions
- interruptions
- cognitive load


Increase:

- confidence
- clarity
- predictability


---

# AI Generation Instruction


When creating a MUJI-style application:

Follow:

1. Keep primary navigation under 5 items.
2. Hide secondary complexity.
3. Prioritize user intention.
4. Use whitespace intentionally.
5. Avoid visual noise.
6. Make every component meaningful.


The final experience should feel:

quiet,
premium,
functional,
timeless.
